# Desktop contracts owner

This source tree is the canonical owner for document schemas/state, command definitions, preference schemas, platform values, and overlay/composition rules. Version 0.1.0 is private and copied with standalone templates. Electron bridge, SQLite, permissions, windows, profile startup, and packaging remain in their host.

Use `src/useSavedDocument.ts` with `DocumentAdapter` from `src/documents.ts`. The adapter provides revision-checked create/save/delete, bounded `list(offset, limit)` range reads, selected-document session methods, and document invalidations. Reads must preserve `(updatedAt DESC, id)` order. `ready()` is optional for synchronous Electron listeners; async hosts must await listener registration before startup reads. `createAsyncSubscription` supplies synchronous cleanup and explicit readiness for those hosts. The hook keeps committed writes separate from retryable list failures and refreshes one loaded range after coalesced invalidations.

Product variants inject `showcaseEnabled` into portable command availability and shortcut validation. Native platform strings enter through `desktopPlatform`; portable consumers have no Node types. Native shell, imports, IPC, release and storage code are not exported.

After a reviewed source change, run `node scripts/desktop-contract-export.mjs --write` from the Electron root. This records per-file SHA-256 hashes and a content-bound source revision in `export-manifest.json`. Run the same script without `--write` to reject drift. Copy the complete package and manifest to another template, preserve that manifest, and compare each hash before adoption. Hosts must run the canonical unit fixtures and their own subscription/transport tests before a shared review finding is complete. Tauri consumes a revision-checked copy of this package. Its build generates native command enums/specifications from command-catalogue.json, then regenerates the bindings through tauri-specta. The catalogue JSON is generated from canonical commands.ts and checked for drift. Windows/Linux and physical native acceptance remain separate review gates.

Hosts select a text policy explicitly. Electron retains UTF-16 unit limits; Tauri retains Unicode scalar limits. text-vectors.json is shared by TypeScript and Rust checks, with the byte cap tested separately. A failed async listener registration stays failed until the application creates a fresh owner after reload. List failures expose listError plus the read-only refreshDocuments action; they do not repeat acknowledged writes. The manifest also binds the copied Node-only setup and release-source helpers. Those tools are not renderer exports.

The package also owns 52 shared interface modules and four shared style sheets. `shared-ui-files.json` lists these sources. Each host path is a checked re-export or CSS import. The `@desktop/*` alias supplies that host's frontend composition and native context. The `@contracts/*` alias points to this package's portable contracts. TypeScript, Vite, and Vitest use both aliases. Native adapters, boot, route composition, native settings, brand tokens, and window styles stay local. The export checks reject a changed host wrapper as well as a changed package file.

For an existing reviewed export set, run `node scripts/sync-desktop-contracts.mjs ../Tauri-React-Boilerplate` to preview, then add `--apply` to synchronize. This command checks both manifests and target hashes, refuses edited files or changed export sets, and uses the recoverable staged publication helper. Run Tauri's `node scripts/check-desktop-contracts.mjs` and `pnpm check` after synchronization. New or removed exports require a separate host-wrapper review before this command can run.
